Which ads are working in gaming and esports?

Pick a topic and a country. The detective reads Meta's public Ad Library and ranks advertisers by how long their ads keep running. Long runs usually mean an ad pays for itself. It is a signal, not proof.

Who it's for: marketers, creative strategists and researchers in gaming and esports who want to see which competitors' ads keep running.

What the detective cannot see

  • No spend, no sales.Meta does not publish spend or results for regular ads. Only political and issue ads carry that.
  • Run time is a clue.An ad that stays live for months is probably paying for itself. A new ad tells you nothing yet.
  • UK and EU only.Meta's API returns every ad only for ads delivered in the UK and the EU. Other countries are not covered.
  • Links, not copies.He links to each ad in Meta's library. He does not store ad images or videos.

Questions

FAQ

Does it save my searches?

No. Searches are sent to Meta through the server and are not stored. The server keeps results in memory for up to ten minutes so repeat searches are fast.

Is this spying?

No. It only reads Meta's public Ad Library, which anyone can open. It adds ranking and a summary.

Why only the UK and EU?

Meta's Ad Library API gives full data for every ad only where the law requires it. For other countries it returns political ads only.

Is the data live?

It comes straight from Meta when you search, up to ten minutes old if someone searched the same thing just before.

What is sample data?

When the server has no Meta access yet, the page shows invented advertisers, each marked Sample, so you can see how a case file looks. None of them are real.
