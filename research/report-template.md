# Report template

Keep the headings in this order so reports can be compared over time.

**Title:** Ad research: [project] ([country], [month year])

1. **Brief.** Project, goal, audience, niche, country, platforms, competitors covered, date, defaults used.
2. **Top ads (5 to 10).** For each: advertiser, platform, start date, versions, format, hook, angle, offer, call to action, link to the ad, link to the landing page, confidence, and the visual notes (style, opening, text on screen, colours, layout).
3. **Patterns.** Angles and hooks, with the number of advertisers using each.
4. **Visual patterns.** Styles, formats and colour approaches, with the number of advertisers using each.
5. **Landing page notes.** What the best pages do.
6. **Gaps and opportunities.** Three to five, each with a one-line reason.
7. **Test plan.** Three concepts, each with hook, angle, offer and a short creative brief.
8. **Limits.** Sources that were blocked or empty, data that was not available, anything uncertain.
9. **Sources.** Every page opened, as full links.
